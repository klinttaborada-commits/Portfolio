# Klint Taborada - IT Portfolio

Plain HTML, CSS, and JavaScript portfolio. Published with GitHub Pages.

## Run locally
Open the folder in VS Code, install **Live Preview** (Microsoft), open `index.html`, and click the preview button.

## Edit checklist
Search the project for `EDIT` and replace every placeholder (email, GitHub link, projects, about text, images).

## Tools used
- AI assistant (Claude): generated the starting design and code; personalized and checked by me.
- VS Code, Git, GitHub Pages.
